# 9. Entry and Exit Criteria

## Entry Criteria

- Staging environment is available and stable
- Test accounts with required roles are provisioned
- Mobile application builds (debug + release) are provided
- API documentation (OpenAPI / GraphQL schema) is available
- Scope and rules of engagement are signed off
- Legal / compliance approval for testing is obtained

## Exit Criteria

- All planned test cases executed or formally deferred
- All Critical and High findings have been remediated or accepted with documented risk acceptance
- Medium findings have owners and target dates
- Final report delivered and accepted by stakeholders
- Retesting of fixed issues completed (or scheduled)
