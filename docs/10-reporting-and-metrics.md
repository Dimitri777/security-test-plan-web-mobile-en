# 10. Reporting and Metrics

## Report Structure

1. Executive Summary
2. Scope and Methodology
3. Risk Summary (charts)
4. Detailed Findings (one per issue)
5. Recommendations and Roadmap
6. Appendices (tools, evidence, retest results)

## Finding Severity

- **Critical** — immediate risk of financial loss or large-scale data breach
- **High** — significant risk, should be fixed before next release
- **Medium** — moderate risk, plan remediation
- **Low** — minor issues / best-practice deviations
- **Informational** — observations

## Key Metrics

- Number of findings by severity
- Time to remediate Critical/High
- Coverage of ASVS / MASVS controls
- False positive rate of automated tools
